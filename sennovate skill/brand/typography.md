# Sennovate Typography System

**Authority:** `[OFFICIAL BRAND RULE]` for Typefaces & Documented Hierarchy; `[PRODUCT UI STANDARD]` for Additional UI Sizes.  
**Source:** Sennovate Brand Guidelines (Slides 16–18)

---

## 1. Typefaces & Roles `[OFFICIAL BRAND RULE]`

1. **Primary Typeface: Satoshi (Slide 16)**
   * **Chosen for:** Clean, modern, highly legible design with geometric structure and balanced proportions.
   * **Usage:** Websites, marketing collaterals, social media, print collaterals, main headings.
   * **Weights:** Bold (700), Medium (500), Regular (400).

2. **Secondary Typeface: Inter (Slide 17)**
   * **Chosen for:** General usage, body text, sub headings, and digital interfaces.
   * **Usage:** Websites, long-form content, UI elements, data tables.
   * **Weights:** Light (300), Regular (400), Medium (500).

---

## 2. Documented Typeface Hierarchy `[OFFICIAL BRAND RULE]`

Directly extracted from **Slide 18** (*Typeface Hierarchy*):

| Level | Typeface | Size | Weight | Role / Purpose |
| :--- | :--- | :--- | :--- | :--- |
| **Main Heading** | **Satoshi** | `32pt` (~42px) | **Bold** (700) | Primary view title, hero display |
| **Sub Heading** | **Inter** | `24pt` (~32px) | **Regular** (400) | Section titles, panel headers |
| **Body** | **Inter** | `18pt` (~24px) | **Regular** (400) | Primary long-form copy, descriptions |
| **Sub Text** | **Inter** | `14pt` (~18px) | **Regular** (400) | Supporting text, captions, secondary info |

---

## 3. Supplementary Application UI Type Scale `[PRODUCT UI STANDARD]`

For dense web applications, dashboards, and tables:

| Level | Size | Line Height | Font Family | Usage |
| :--- | :--- | :--- | :--- | :--- |
| **UI Body Default** | 14px | 20px | Inter Regular (400) | Standard table rows, inputs, buttons |
| **UI Caption / Meta** | 12px | 16px | Inter Regular (400) | Helper text, timestamps, table subtext |
| **UI Badge / Micro** | 11px | 14px | Inter Medium (500) | Status pills, count badges |
| **Code / Data** | 13px | 18px | Monospace | API keys, hashes, JSON payloads |
