# Sennovate Logo System

**Authority:** `[OFFICIAL BRAND RULE]`  
**Source:** Sennovate Brand Guidelines (Slides 12–21)

---

## 1. Logo Construction & Anatomy

The Sennovate brand identifier consists of two core elements:
1. **The Wordmark:** Geometric lowercase lettering `sennovate`.
2. **The Shield Emblem:** A protective shield motif with diagonal internal stripes embedded within the letter `o`.

The shield emblem represents cybersecurity vigilance, zero-trust architecture, and modern cryptographic protection.

## 3. Clear Space Rule (`1X`)

The minimum clear space around the logo is defined by the unit **`X`**:
* **`X`** is defined as the height of the inner shield emblem icon.
* No text, icons, borders, or layout margins may enter this `1X` exclusion boundary.

```
       +---------------------------------------------+
       |                  [ 1X ]                     |
       |  [ 1X ]    s e n n [ O ] v a t e   [ 1X ]   |
       |                  [ 1X ]                     |
       +---------------------------------------------+
```

---

## 4. Minimum Reproduction Sizes

To preserve legibility and shield detail:

* **Digital Screens:**
  * Full Wordmark: Minimum width **`120px`**
  * Shield Icon / Favicon: Minimum width **`32px`**
* **Print Applications:**
  * Full Wordmark: Minimum width **`25mm`**
  * Shield Icon: Minimum width **`8mm`**

---

## 5. Logo Misuse Rules (Strictly Prohibited)

An AI agent or developer must **NEVER**:
1. ❌ **Distort or Stretch:** Never alter horizontal or vertical aspect ratio.
2. ❌ **Rotate:** Never tilt, slant, or display the logo at an angle.
3. ❌ **Add Effects:** Never add drop shadows, outer glows, bevels, 3D extrusions, or strokes.
4. ❌ **Alter Colors:** Never change the color of individual letters or the shield emblem.
5. ❌ **Low Contrast:** Never place the dark logo on dark navy or the white logo on light grey.
6. ❌ **Busy Backgrounds:** Never place the logo over visually noisy patterns or unfiltered photography.
7. ❌ **Rearrange:** Never separate the shield from the wordmark to create custom lockups without authorization.
